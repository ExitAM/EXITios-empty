# EXITios deployment

This repository contains the revised EXITios frontend and exported Base44 project configuration. GitHub source storage does not automatically establish Base44 sync.

Do not deploy an unconfigured `npm run build` output: the Base44 app ID and backend URL must be supplied by the linked app workflow. See README.md and IMPLEMENTATION-NOTES.md for setup, validation, and remaining backend work.

No production deployment has been performed by this commit.
